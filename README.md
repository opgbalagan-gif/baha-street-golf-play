# DOGMA FIGHT — FORYGUNZ × Мутки

[Играть в DOGMA FIGHT на телефоне](https://opgbalagan-gif.github.io/baha-street-golf-play/fight/)

Горизонтальный видеофайтинг: выберите одного или двух игроков. В одиночном режиме можно выбрать бойца. Перед первым раундом — обучение; матч идёт до двух побед. На телефоне поверните экран горизонтально и тапайте по своей стороне. Начальный экран открывается без ожидания анимаций; видео подгружаются по ходу игры. Общий объём материалов — около 10 МБ.

После старта играет Drop Top с эхом по видеопримеру. Трек продолжается при смене роликов; в заставках оставлены голос и эффекты. В нижнем правом углу заставок и боя — полупрозрачный логотип DOGMA.
