# DOGMA FIGHT — FORYGUNZ × Мутки

[Играть в DOGMA FIGHT на телефоне](https://opgbalagan-gif.github.io/baha-street-golf-play/fight/)

Горизонтальный видеофайтинг: выберите одного или двух игроков. В одиночном режиме можно выбрать бойца. В начале первого раунда — замедленное видео и «ЖМИ» на затемнённой половине выбранного бойца. Первый тап начинает бой и сразу засчитывается; матч идёт до двух побед. На телефоне поверните экран горизонтально и тапайте по своей стороне. Начальный экран открывается без ожидания анимаций; видео подгружаются по ходу игры. Общий объём материалов — около 10 МБ.

После старта играет Drop Top с эхом по видеопримеру. Трек продолжается при смене роликов; в заставках оставлены голос и эффекты. В нижнем правом углу заставок и боя — полупрозрачный логотип DOGMA.

Кадр показывается целиком в формате 16:9, без растяжения и обрезки. Двойной тап засчитывает два нажатия и не увеличивает страницу. На телефонах с поддержкой Fullscreen API полный экран включается при старте игры.

На iPhone для запуска без панелей браузера откройте игру в Safari → «Поделиться» → «На экран „Домой“». Включите «Открывать как веб-приложение», если такой пункт есть, и запускайте DOGMA по новой иконке. Кнопка «НА ВЕСЬ ЭКРАН» показывает три крупных шага с иконками Safari, «Поделиться» и «На экран „Домой“», если браузер не разрешает включить полный экран напрямую.
